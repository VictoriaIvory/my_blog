ABOUT

关于这个博客

一个用 Django 写的个人博客，记录项目里真实遇到的问题。

为什么写

很多坑当时踩得很痛，过两周就忘了细节，下次还会再踩一遍。 所以把「现象 → 当时怎么想的 → 错在哪 → 最后怎么解决」写下来， 更像是留给几周后自己的备忘，而不是教程。

文章里出现的项目都是自己做的：投票系统、这个博客本身， 以及平时练习 Django 时写的小东西。写出来的每个问题都能指着代码说清楚。

用了什么

后端Python 3.12 · Django 5.2 LTS
数据库SQLite（个人博客够用，备份就是拷一个文件）
正文Markdown 渲染 + Pygments 代码高亮 + bleach 白名单清洗
前端手写 HTML / CSS，没有框架、不依赖外部 CDN
测试Django 测试 + GitHub Actions 每次 push 自动跑
